# Lumea Retreats

A luxury retreat and hospitality website designed to showcase premium stays, experiences, destinations, and curated travel moments.

## ✦ About

Lumea Retreats is a responsive hospitality website focused on creating an elegant and immersive booking experience through refined layouts, interactive sections, and modern visual design.

## 🛠️ Technologies

* HTML5
* CSS3
* Vanilla JavaScript

## ✨ Features

* Luxury hero section
* Interactive booking bar
* Featured stays
* Travel experiences
* Destinations section
* Gallery with category filters
* Newsletter subscription
* Booking modal
* Dark mode
* Wishlist interactions
* Search functionality
* Date validation
* Toast notifications
* Back-to-top button
* Scroll reveal animations
* Responsive mobile design

## 🚀 Project

Lumea Retreats was built from scratch using core web technologies without a frontend framework, focusing on responsive design, smooth interactions, and a premium hospitality aesthetic.
